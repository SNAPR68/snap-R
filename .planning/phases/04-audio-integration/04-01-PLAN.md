# Plan 04-01: Background Music Library + Audio Component

## Goal
Add royalty-free background music tracks as static files and create a reusable audio layer component that all compositions can use for music, voiceover, fades, and ducking.

## Tasks

### Task 1: Create music directory with placeholder tracks

Since we can't download copyrighted music programmatically, create tiny silent placeholder MP3 files that can be replaced with real royalty-free tracks later. This unblocks the entire audio pipeline.

**Create**: `public/music/` directory with 5 files:
- `upbeat.mp3` — placeholder (will replace with real track)
- `elegant.mp3`
- `cinematic.mp3`
- `ambient.mp3`
- `corporate.mp3`
- `silent.mp3` — 1-second silent track for platform compatibility

**Approach**: Generate minimal valid MP3 files using `ffmpeg` (if available) or use a tiny base64-encoded silent MP3 (~200 bytes). These are functional placeholders that produce no sound but are valid MP3 files the rendering pipeline can consume.

### Task 2: Create AudioLayer composition component

**Create**: `remotion/compositions/AudioLayer.tsx`

This is a reusable component that all compositions render as a sibling to their visual content. It handles:

- **Background music** via `<Audio>` from `@remotion/media`
  - Source: `staticFile(`music/${musicTrack}.mp3`)` or remote URL
  - `loop` enabled (tracks may be shorter than video)
  - Volume callback with fade in (first 30 frames / 1s) and fade out (last 30 frames / 1s)
  - When voiceover is present: duck to `musicVolume * 0.3`
- **Voiceover** via `<Audio>` from `@remotion/media`
  - Source: remote URL (Supabase Storage signed URL)
  - Volume: `voiceoverVolume` (0-1 range, converted from UI's 0-100)
- **Silent track** when no music and no voiceover
  - `staticFile('music/silent.mp3')` with `loop` for platform compatibility

**Props schema** (Zod):
```typescript
audioSchema = z.object({
  musicTrack: z.string().optional(),       // 'upbeat' | 'elegant' | etc. or undefined
  musicUrl: z.string().url().optional(),    // Override: direct URL to music file
  musicVolume: z.number().min(0).max(1).default(0.3),
  voiceoverUrl: z.string().url().optional(), // Signed URL to voiceover MP3
  voiceoverVolume: z.number().min(0).max(1).default(1),
})
```

**Volume ducking implementation**:
```typescript
const musicVolumeCallback = (frame: number) => {
  const fadeIn = interpolate(frame, [0, fadeFrames], [0, 1], { extrapolateRight: 'clamp' });
  const fadeOut = interpolate(frame, [totalFrames - fadeFrames, totalFrames], [1, 0], { extrapolateLeft: 'clamp' });
  const fade = Math.min(fadeIn, fadeOut);
  const duck = hasVoiceover ? 0.3 : 1.0;
  return musicVolume * fade * duck;
};
```
