# Plan 04-02: Voiceover Upload + Generate API Audio Params

## Goal
Wire voiceover audio persistence (upload to Supabase Storage) and pass audio parameters through the generate API to Lambda, completing the server-side audio pipeline.

## Tasks

### Task 1: Voiceover upload endpoint

**Modify**: `app/api/video/voiceover/route.ts`

Add a new action `upload-audio` that:
1. Receives base64 audio from the `generate-audio` response
2. Uploads the MP3 buffer to Supabase Storage bucket `voiceovers` (or `raw-images` with a `voiceovers/` prefix)
3. Creates a signed URL (1 hour expiry — long enough for Lambda render)
4. Returns `{ voiceoverUrl: string, duration: number }`

Also fix the existing `any` types in this file (catch blocks use `error: any`, function params use `any`).

**Create** (if needed): Supabase Storage bucket for voiceovers — or use existing `raw-images` bucket with prefix.

### Task 2: Update generate video schema + API route

**Modify**: `lib/validation/schemas.ts`

Extend `generateVideoSchema`:
```typescript
export const generateVideoSchema = z.object({
  listingId: z.string().uuid(),
  aspectRatio: z.enum(['9:16', '1:1', '16:9']),
  template: z.enum(['test', 'property-showcase', 'just-listed', 'open-house']),
  openHouseDate: z.string().max(100).optional(),
  audio: z.object({
    musicTrack: z.string().max(50).optional(),
    musicVolume: z.number().min(0).max(100).optional(),
    voiceoverUrl: z.string().url().optional(),
    voiceoverVolume: z.number().min(0).max(100).optional(),
  }).optional(),
})
```

**Modify**: `app/api/video/generate/route.ts`

Pass audio params through to Lambda inputProps:
```typescript
if (validatedInput.audio) {
  inputProps.audio = {
    musicTrack: validatedInput.audio.musicTrack,
    musicVolume: (validatedInput.audio.musicVolume ?? 30) / 100,
    voiceoverUrl: validatedInput.audio.voiceoverUrl,
    voiceoverVolume: (validatedInput.audio.voiceoverVolume ?? 100) / 100,
  };
}
```

Note: UI uses 0-100 range, compositions use 0-1 range. Conversion happens in the API route.
