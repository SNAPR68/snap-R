# Plan 04-03: Wire Audio UI to Render Pipeline

## Goal
Connect the existing VideoCreator audio UI controls to the generate API so that music and voiceover settings flow through to Lambda rendering. Remove the "coming soon" banner.

## Tasks

### Task 1: Wire voiceover generation → upload → URL

**Modify**: `app/dashboard/content-studio/video/VideoCreator.tsx`

Update `generateVoiceover()` function:
1. After receiving base64 audio from `generate-audio` action, make a second call to `upload-audio` action
2. Store the returned `voiceoverUrl` in state (new state: `voiceoverUrl: string | null`)
3. Replace `voiceoverAudio: Blob | null` with `voiceoverUrl: string | null` — we no longer need the Blob since Lambda uses the URL
4. Update the "Voiceover Ready" button state to show when `voiceoverUrl` is set

body: JSON.stringify({
