# Plan 03-02: OpenHouse Composition

## Goal
Build the OpenHouse video template with urgency-focused design — event date/time display, faster-paced slideshow with wipe transitions, and countdown-style closing card.

## Requirements
- COMP-03: OpenHouse template renders date/time urgency with event details
- COMP-08: Wipe transitions for urgency pacing

## Files to Create

### `remotion/compositions/OpenHouse.tsx` — Main composition
- **Zod schema**: listing (address, price, beds, baths, sqft, photos), aspectRatio, openHouseDate (optional string, e.g. "Saturday, March 1st · 1-4 PM")
- **Structure**:
  1. IntroCard (75 frames / 2.5s) — "OPEN HOUSE" title + date/time subtitle + address
  2. Wipe transition (30 frames / 1s) into photo slideshow
  3. Fast-paced photo slideshow with wipe transitions
     - 105 frames per photo (3.5s — shorter than PropertyShowcase's 4.5s for urgency)
     - Wipe transition between photos (30 frames / 1s — faster than 1.5s)
     - Ken Burns still applied (shared PhotoSlide component)
  4. Event details persistent overlay: date/time badge at top of frame
  5. Fade transition into ClosingCard with "Join Us" text addition (90 frames / 3s)
- **Duration calculation**: `INTRO_FRAMES + photoCount * (OH_PHOTO_FRAMES - OH_WIPE_FRAMES) + OH_WIPE_FRAMES + CLOSING_CARD_FRAMES`
- **Urgency styling**: Slightly warm color shift on overlays, pulsing clock icon possibility
- Export: `openHouseSchema`, `OpenHouseProps`, `calculateOpenHouseDuration()`, `OpenHouse`

### `remotion/compositions/EventBadge.tsx` — Date/time overlay badge
- **Props**: `dateText` (string), optional `icon` ('calendar' | 'clock')
- Semi-transparent dark badge at top of frame
- Calendar icon + date text
- Fade in on first photo, persistent throughout slideshow
- Percentage-based sizing: height * 0.03 for text
