# Plan 03-03: Template Selection UI + API Integration

## Goal
Add template selector to VideoCreator UI, extend the generate API to support new templates, and wire up the full flow.

## Requirements
- UI-03: Template selector dropdown with preview thumbnails for each template
- COMP-08: Transition type selection (fade, slide, wipe)

## Files to Modify

### `lib/validation/schemas.ts`
- Expand template enum: `z.enum(['test', 'property-showcase', 'just-listed', 'open-house'])`

### `app/api/video/generate/route.ts`
- Extend `getCompositionId()` with new template mappings:
  ```
  just-listed + 9:16 → JustListed-9x16
  just-listed + 1:1  → JustListed-1x1
  just-listed + 16:9 → JustListed-16x9
  open-house + 9:16  → OpenHouse-9x16
  open-house + 1:1   → OpenHouse-1x1
  open-house + 16:9  → OpenHouse-16x9
  ```
- Extend `ListingWithPhotos` to include `features` field from DB
- Pass `features` to Lambda inputProps for JustListed template
- Accept optional `openHouseDate` in request body (pass through to Lambda inputProps for OpenHouse)
- Extend Zod schema to accept optional `openHouseDate: z.string().optional()`

### `app/dashboard/content-studio/video/VideoCreator.tsx`
- Add template type: `type VideoTemplate = 'property-showcase' | 'just-listed' | 'open-house'`
- Add `TEMPLATES` constant with name, description, icon for each
- Add `template` state (default: 'property-showcase')
- Add template selector UI in the Video tab settings area:
  - 3 clickable cards (similar pattern to aspect ratio selector)
  - Each card: template name + 1-line description + icon
  - Active card highlighted with gold border (#D4A017)
- When template is 'open-house', show optional date/time text input
- Add `openHouseDate` state
- Pass `template` and `openHouseDate` to generate API call
- Pass listing features to generate API (already available from listingData)
