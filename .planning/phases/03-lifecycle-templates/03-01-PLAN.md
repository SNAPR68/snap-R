# Plan 03-01: JustListed Composition

## Goal
Build the JustListed video template with animated intro card, photo slideshow with slide transitions, feature callouts, and closing card.

## Requirements
- COMP-02: JustListed template renders "JUST LISTED" intro card, photo slideshow, feature callouts, and agent branding end card
- COMP-08: Slide transitions alongside fade

## Files to Create

### `remotion/compositions/shared.tsx` — Shared video components
Extract and extend reusable components:
- `PhotoSlide` — Ken Burns photo component (extracted from PropertyShowcase)
- `AddressOverlay` — Persistent address text overlay
- `fontFamily` — Inter font loading (shared across all compositions)
- `PHOTO_DISPLAY_FRAMES`, `CROSSFADE_FRAMES`, `CLOSING_CARD_FRAMES` — Shared timing constants

### `remotion/compositions/IntroCard.tsx` — Animated intro card
- **Props**: `title` (string, e.g. "JUST LISTED"), `subtitle` (optional, e.g. address)
- **Animation**: Dark background (#0A0A0A)
  - Title text: scale from 0.8→1.0 + fade in over 20 frames, gold accent line animates width from 0→100% below
  - Subtitle: fade in + slide up 10 frames after title
  - Font: Inter 800 weight, gold (#D4A017) accent
- **Duration**: 75 frames (2.5 seconds)
- Percentage-based sizing (height * 0.08 for title)

### `remotion/compositions/FeatureCallout.tsx` — Animated feature overlay
- **Props**: `features` (string array), `startIndex` (which feature to show)
- Shows 1 feature at a time as overlay text on photo slides
- Animation: fade in from bottom, hold, fade out
- Small semi-transparent pill/badge at bottom-right
- Percentage-based sizing
- Features shown: first N features (one per photo, cycling)

### `remotion/compositions/JustListed.tsx` — Main composition
- **Zod schema**: listing (address, price, beds, baths, sqft, photos, features), aspectRatio
- **Structure**:
  1. IntroCard (75 frames / 2.5s) — "JUST LISTED" + address
  2. Slide transition (30 frames / 1s) into photo slideshow
  3. Photo slideshow with slide transitions (alternating from-left/from-right)
     - PHOTO_DISPLAY_FRAMES per photo (135 frames / 4.5s)
     - Slide transition between photos (45 frames / 1.5s)
  4. Feature callouts overlaid on photos (1 feature per photo)
  5. Fade transition into ClosingCard (90 frames / 3s)
- **Duration calculation**: `INTRO_FRAMES + photoCount * (PHOTO_DISPLAY_FRAMES - SLIDE_FRAMES) + SLIDE_FRAMES + CLOSING_CARD_FRAMES`
- Export: `justListedSchema`, `JustListedProps`, `calculateJustListedDuration()`, `JustListed`
