- Structure:

  2. `<TransitionSeries>` containing:
     - For each photo: `<TransitionSeries.Sequence durationInFrames={PHOTO_DISPLAY_SECONDS * fps}>` wrapping `<PhotoSlide src={photo} index={i} durationInFrames={PHOTO_DISPLAY_SECONDS * fps} />`
     - Between photos: `<TransitionSeries.Transition presentation={fade()} timing={{ durationInFrames: Math.round(CROSSFADE_SECONDS * fps) }} />`
     - After last photo: transition + closing card sequence
  3. `<AddressOverlay address={listing.address} />` rendered OUTSIDE TransitionSeries (persistent, on top of everything)
- Closing card is the LAST sequence in TransitionSeries, with a crossfade from last photo (maintains continuous flow per user's "dreamy luxury feel" requirement)
- Use React fragment `<>` inside map for transition + sequence pairs
- Handle edge case: if photos array is empty, show only closing card

Export `calculateDuration` function:
```typescript
export function calculateDuration(photoCount: number, fps: number): number {
  const photoFrames = photoCount * PHOTO_DISPLAY_SECONDS * fps;
  const transitionFrames = Math.max(0, photoCount - 1) * CROSSFADE_SECONDS * fps;
  const closingFrames = CLOSING_CARD_SECONDS * fps;
  const closingTransition = CROSSFADE_SECONDS * fps; // transition into closing card
  return Math.round(photoFrames - transitionFrames + closingFrames + closingTransition);
}
```
Note: TransitionSeries overlaps transitions (they don't add time, they overlap adjacent sequences), so total = sum of sequences - sum of overlaps. But the closing card transition DOES add because it's the last transition before a new sequence.

Actually, the correct calculation for TransitionSeries total duration:
- Each sequence has `durationInFrames`
- Each transition SUBTRACTS its duration from the total (overlap)
- Total = sum(sequence durations) - sum(transition durations)
- For N photos + 1 closing card = N+1 sequences, N transitions (N-1 between photos + 1 into closing)
- Total = (N * photoDuration + closingDuration) - (N * transitionDuration)

```typescript
export function calculateDuration(photoCount: number, fps: number): number {
  const photoDuration = Math.round(PHOTO_DISPLAY_SECONDS * fps);
  const transitionDuration = Math.round(CROSSFADE_SECONDS * fps);
  const closingDuration = Math.round(CLOSING_CARD_SECONDS * fps);
  // N photo sequences + 1 closing card sequence - N transitions
  return (photoCount * photoDuration) + closingDuration - (photoCount * transitionDuration);
}
```
