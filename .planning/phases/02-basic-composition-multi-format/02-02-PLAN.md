const WALKTHROUGH_ORDER: PhotoType[] = [
  'exterior_front',
  'exterior_side',
  'interior_living',
  'interior_kitchen',
  'interior_dining',
  'interior_bedroom',
  'interior_bathroom',

  'detail',
  'unknown',

This order matches the user's requested flow: Exterior → Entryway → Living → Kitchen → Dining → Bedrooms → Bathrooms → Outdoor. Note: no explicit "entryway" in PhotoType — interior_living is typically the first interior shot after entrance.

**Interface for photo input:**
```typescript
interface PhotoWithUrl {
  id: string;
  processed_url: string;
}
```

**Interface for photoAudit data from preparation_metadata:**
```typescript
interface PhotoAuditEntry {
  photoType?: string;
  heroScore?: number;
  [key: string]: unknown;
}
```

**Main export function:**
```typescript
export function orderPhotosForWalkthrough(
  photos: PhotoWithUrl[],
  photoAudit?: Record<string, PhotoAuditEntry> | null
): PhotoWithUrl[] {
  // If no audit data available, return original order
  if (!photoAudit || Object.keys(photoAudit).length === 0) {
    return photos;
  }

  // Sort photos by walkthrough order based on photoType from audit
  return [...photos].sort((a, b) => {
    const aType = (photoAudit[a.id]?.photoType ?? 'unknown') as PhotoType;
    const bType = (photoAudit[b.id]?.photoType ?? 'unknown') as PhotoType;

    const aIndex = WALKTHROUGH_ORDER.indexOf(aType);
    const bIndex = WALKTHROUGH_ORDER.indexOf(bType);

    // If photoType not in order list, put at end
    const aPos = aIndex === -1 ? WALKTHROUGH_ORDER.length : aIndex;
    const bPos = bIndex === -1 ? WALKTHROUGH_ORDER.length : bIndex;

    if (aPos !== bPos) return aPos - bPos;

    // Within same type, sort by heroScore descending (best photo first)
    const aScore = photoAudit[a.id]?.heroScore ?? 0;
    const bScore = photoAudit[b.id]?.heroScore ?? 0;
    return bScore - aScore;
  });
}
```

Key design decisions:
- **Zero AI cost**: Uses existing photoAudit data from preparation flow (no GPT-4o Vision call needed)
- **Graceful fallback**: If photoAudit is null/empty (unprepared listing), returns original order — never breaks
- **Type safety**: Uses PhotoType from existing types.ts — no new types invented
- **Tiebreaker**: Within same room type, sorts by heroScore descending (best photos shown first)
- **Immutable**: Creates a copy with spread (`[...photos]`) before sorting — never mutates input
