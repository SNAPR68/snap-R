# Plan 05-02: Marketing Status API + Results Panel Video Card

## Goal
Expose video step data through the marketing status API and display it in the Marketing Results Panel UI.

## Tasks

### Task 1: Update Marketing Status API
Modify `app/api/marketing/status/route.ts`:
- Add `video` to the response shape:
  ```
  video: {
    status: marketingJob.video_status,
    result: marketingJob.video_result,
  }
  ```
- Also fix the existing `catch (error: any)` → `catch (error: unknown)`

### Task 2: Update MarketingJobData Type
Modify `components/marketing-banner.tsx`:
- Add `video` to `MarketingJobData` type:
  ```
  video: { status: string; result: MarketingStepResult };
  ```

### Task 3: Update Marketing Banner
Modify `components/marketing-banner.tsx`:
- Add Video to STEPS array:
  ```
  { key: 'video', label: 'Video', icon: Video }
  ```
- Import `Video` icon from lucide-react
- Progress dots now show 6 steps
- Step counter shows X/6

### Task 4: Update Marketing Results Panel
Modify `components/marketing-results-panel.tsx`:
- Add 6th CollapsibleSection for "Property Video"
- Import `Video` icon from lucide-react
- When video_status === 'completed' and result has videoUrl:
  - Show HTML5 `<video>` element with controls
  - Download button
- When video_status === 'rendering':
  - Show "Rendering..." with spinner
- When video_status === 'skipped':
  - Show upgrade prompt
- When video_status === 'failed':
  - Show error message

### Task 5: Video URL Resolution
The `video_result` JSONB contains `renderId` and `bucketName` (fire-and-forget).
The actual `videoUrl` comes from `video_render_jobs.video_url` after render completes.

Two options:
A) Marketing status API also queries video_render_jobs to get videoUrl — adds complexity
B) Store videoUrl in video_result after render completes — requires callback mechanism

**Chosen: Option A** — Marketing status API joins video_render_jobs to get latest videoUrl.
When `video_result.renderId` exists, query `video_render_jobs` for that renderId and merge `video_url` into the response.
