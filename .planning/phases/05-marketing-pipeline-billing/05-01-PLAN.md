**FINAL APPROACH — Internal API route:**
Create `/api/internal/video-generate` that:
1. Accepts `Authorization: Bearer CRON_SECRET` (same pattern as cron jobs)

4. Returns `{ renderId, bucketName }`

The marketing handler calls this internal endpoint from the Worker.

### Task 4: Internal Video Generate Endpoint
Create `app/api/internal/video-generate/route.ts`:
- Same auth pattern as cron: `Authorization: Bearer CRON_SECRET`
- Accept `{ listingId, userId, template, aspectRatio }`
- Fetch listing + photos using adminSupabase (no user session needed)
- Order photos, resolve composition, trigger Lambda render
- Store in video_render_jobs
- Return `{ renderId, bucketName }`
