<task type="auto">
  <name>Task 2: Create video_render_jobs database migration and Zod schemas</name>
  <files>
    supabase/migrations/20260219_video_render_jobs.sql
    lib/validation/schemas.ts
  </files>
  <action>
1. Create `supabase/migrations/20260219_video_render_jobs.sql`:
   ```sql
   CREATE TABLE video_render_jobs (
     id uuid PRIMARY KEY DEFAULT uuid_generate_v4(),
     user_id uuid REFERENCES auth.users NOT NULL,
     listing_id uuid REFERENCES listings NOT NULL,
     render_id text NOT NULL UNIQUE,
     bucket_name text,
     status text NOT NULL DEFAULT 'queued',
     video_url text,
     input_props jsonb NOT NULL,
     render_time_ms integer,
     cost_cents integer,
     error text,
     created_at timestamptz DEFAULT now(),
     updated_at timestamptz DEFAULT now()
   );
   ```
   - Add CHECK constraint on status: `CHECK (status IN ('queued', 'rendering', 'completed', 'failed'))`
   - Add indexes on: `user_id`, `listing_id`, `render_id`, `status`, `created_at DESC`
   - Enable RLS: `ALTER TABLE video_render_jobs ENABLE ROW LEVEL SECURITY;`
   - Create SELECT policy for authenticated users: `USING (auth.uid() = user_id)`
   - Create ALL policy for service role: `USING (auth.role() = 'service_role')` — this allows admin client to insert/update

2. Add Zod schemas to `lib/validation/schemas.ts`:
   - Add `generateVideoSchema`:
     ```typescript
     export const generateVideoSchema = z.object({
       listingId: z.string().uuid(),
       aspectRatio: z.enum(['9:16', '1:1', '16:9']),
       template: z.enum(['test']),
     })
     ```
   - Add `videoStatusSchema`:
     ```typescript
     export const videoStatusSchema = z.object({
       renderId: z.string().min(1).max(200),
     })
     ```
   - Place these at the end of the existing schemas file, after the existing exports
   - Do NOT modify any existing schemas
  </action>
